# Changelog / 版本记录

## 1.0.0 — 2026-11-26

- 发布单块 8×32 灯板的日历天气、中文轮播与收藏、像素鸭、游戏和照明功能。Publish the single-panel clock, weather, phrase/favorites, duck, game and lamp baseline.
- 保留 Windows GUI、无窗口取音及手机网页切换波形/频谱。Include Windows controls, headless audio and phone-selected visualizations.
- 公开副本移除固定设备 MAC 和私人目录依赖，改为显式本地配置。Replace personal identity and workstation paths with explicit local configuration.
- 热点密码改为每台设备首次启动生成并持久化，串口本地读取。Generate and persist an individual AP password on first boot.
- 补齐双语说明、字体工具路径、第三方授权和验证边界。Add bilingual documentation, portable font tooling, notices and validation scope.

## Hardware baseline / 实机基线 — 2026-11-25

中文编辑、收藏、错误输入、重启恢复和轮播顺序经过实机检查。Public-release password and identity changes are distinct from this earlier hardware evidence.
